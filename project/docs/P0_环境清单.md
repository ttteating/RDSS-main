### 2.1 服务器首次部署（可直接粘贴，Linux）

```bash
# 1) 环境（如服务器无 conda，用 venv 亦可）
conda create -n rdss python=3.10 -y && conda activate rdss

# 2) 依赖（CPU/GPU 版本以服务器 CUDA 为准；cu121 示例）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r project/requirements.txt

# 3) 锁定环境（P0 通过条件之一）
pip freeze > requirements.lock
nvidia-smi > hardware_report.txt

# 4) 一条命令跑 P0 自检（形状 + 配置 + 版本）
cd project && python scripts/check_env.py
```

## 3. 版本与显存约束

1. **版本固定原则**：以实际安装版本为准，`requirements.lock` 必须由 `pip freeze` 在该机器生成，不手写。
2. **8GB 显存取舍（若服务器为 8GB 卡，如本地 RTX 4060 Laptop）**：
   - `fixmatch.amp: true` 必开；
   - `batch_size_labeled: 64` / `batch_unlabeled: 448`；OOM 时先减到 32/224，再用梯度累积补回等效 batch，**任何改动写进 `configs/fixmatch.yaml`**；
   - CLIP 抽特征用 `batch_size: 256` + `no_grad` + autocast，显存不足降到 64。
3. **核矩阵内存**：n=45000 的全核矩阵约 8.1GB（float32），按 `kernel.block_rows: 5000` 分块；σ 的 median heuristic 也用分块距离统计，不一次性开全矩阵。
4. **确定性**：`torch.backends.cudnn.deterministic` 不强制开启（会显著变慢）；随机种子按 `configs/seeds.yaml` 统一设置，报告"同种子可复现到 μ±小量"的实测结论（P3 验证）。

## 4. 已知环境问题

| 问题 | 影响 | 处理 |
|---|---|---|
| 本地 D 盘仅 4.1GB | 无法容纳数据 + 特征 + checkpoint（约 20GB） | 训练迁移服务器；本地只保留代码与文档 |
| 本地无 `transformers` | 无法本地验证 CLIP 分支 | 服务器执行 `scripts/check_env.py` |
| 官方 README 要求 Python 3.8 | 与本地 3.12 不一致 | 统一以服务器实际版本为准，版本写入 `requirements.lock` 与本节表格 |
| 官方 `requirements.txt` 未锁版本（`>=`） | 复现风险 | 本项目 `requirements.txt` 给出下界 + 实际锁定值放 `requirements.lock` |
