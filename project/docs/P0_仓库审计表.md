## B. 论文 ↔ 官方代码不一致（§A7，6 项）

| 编号 | 现象 | 证据 | 主实验口径 | 差异实验 | 记录位置 |
|---|---|---|---|---|---|
| A7-1 | 核带宽：论文 σ = 全池距离中位数；官方写死 `gamma=0.5` | `RDSS.py` L8（`def gaussiankernel(..., gamma=0.5)`） | **median heuristic**：L2 归一化特征上取全池 pairwise 距离中位数，γ=1/σ，写入 `configs/kernel.yaml` | 另跑一次 `gamma_official=0.5`，作为"实现差异"报告 | `kernel.yaml` + P1 报告 |
| A7-2 | 特征取法：论文 final [CLS]；官方 `pooler_output` | `get_cifar_feature.py` L38 | 默认 `cls_last_hidden`（`last_hidden_state[:,0,:]`），三方法统一 | 与 `pooler_output` 的差别**仅在最后一层 post_layernorm**（同一 [CLS]，非不同模型），报告写明实际取法 | `data.yaml: features.take` |
| A7-3 | 基线命名：论文为 Random / k-Means / Stratified / USL / ActiveFT；课程要求 k-center | 论文 §5 对照表；课程 §B5 | 采用 **k-center（core-set 贪心）**，报告中注明"课程新增基线，非论文原基线" | 不做 k-Means（算力与口径风险） | 立项书 §6 |
| A7-4 | 预算与数据：论文 CIFAR-10 m ∈ {40,250,4000}；课程 {250,1000} | `RDSS.py` L41；课程 §B5 | {250, 1000}；m=40 列为可选拓展 | 不跑 4000（算力） | `selection.yaml: budgets` |
| A7-5 | SVHN 分支 bug：误用 cifar100 预算 + `np.array(dict)` | `RDSS.py` L94、L92 | 课程不跑 SVHN，**标注废弃**，不假装可用 | 无 | 本表 C4 |
| A7-6 | **μ 的对角线**：论文 Algorithm 1 的 μ=(1/N)Σ_j k(x_j,x_i) 含自身 k(x_i,x_i)=1；官方显式去对角线 | `RDSS.py` L22-23（`mu = mu - np.diag(np.diag(mu))`） | **先按论文口径（不去对角线）** 实现，`kernel.yaml: mu.diagonal=include` | 已实测：合成特征 n=2000/m=250/α=0.9368/γ=0.7071 下，include 与 exclude 两版都返回与官方**完全相同的索引**；原因是 μ_ex=(n·μ_in−1)/(n−1) 只是 α 缩放 n/(n−1) 加常数偏移，故两者选择几乎总一致，仅近似并列时可能分叉 | `kernel.yaml: mu` + `results/p2/consistency_*.json` |
