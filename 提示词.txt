# §A 论文核心规格（自包含，照此实现，不要凭记忆改写）

## A1 目标函数与记号
输入未标注池 X_n = {x_1,…,x_n}，预算 m < n，低预算设定 m/n ≤ 0.2，采样**无放回**（Σ_m ⊂ [n]，|Σ_m| = m）。
论文把"选得好"拆成两个准则：
- 代表性 Rep = −MMD²_k(X_Σm, X_n)：所选子集要像全池分布
- 多样性 Div = −S_k(X_Σm)：所选样本彼此不能太像
原始目标（论文式 1、5）：
    min_{Σ_m ⊂ [n]}  MMD²_k(X_Σm, X_n) + λ·S_k(X_Σm),   λ = (1 − α)/(α·m)
平均核相似度（论文式 2，值越大 = 选出的样本越冗余）：
    S_k(X_Σm) = (1/m²) Σ_{i∈Σ_m} Σ_{j∈Σ_m} k(x_i, x_j)
经验 MMD（论文式 4）：
    MMD²_k(X_Σm, X_n) = (1/n²)Σ_{i,j=1..n}k(x_i,x_j) + (1/m²)Σ_{i∈Σ_m}Σ_{j∈Σ_m}k(x_i,x_j) − (2/mn)Σ_{i=1..n}Σ_{j∈Σ_m}k(x_i,x_j)

实现**只用化简后的 α-MMD 向量形式**（论文式 6，与上式仅差常数）：
    MMD²_{k,α}(X_Σm, X_n) = || (1/m)·Σ_{i∈Σ_m} φ(x_i) − (α/n)·Σ_{j=1..n} φ(x_j) ||²_H
（φ 为特征抽取器映射，此处即 CLIP [CLS] 特征，不是分类网络的 φ。）
α 语义必须先讲清再写代码：α=1 退化为经典 MMD → 只留代表性、丢掉多样性；α=0 退化为平均相似度 → 只留多样性、丢掉代表性；α 减小 ⇔ λ 增大 ⇔ 更鼓励多样性。

## A2 核函数与超参
- 高斯核 k(x,y) = exp(−||x−y||² / σ)，σ 取全池 pairwise 距离的**中位数**（median heuristic）；等价写法 exp(−γ||x−y||²)、γ = 1/σ。
- 默认 α = 1 − 1/√m；理论可用区间 α ∈ [1 − 1/√m, 1]。代值：m=40 → 0.8419；m=250 → 0.9368；m=1000 → 0.9684；m=4000 → 0.9842。
- 工程建议（非论文规定，需写入配置）：先对 [CLS] 特征做 L2 归一化再算距离，否则特征尺度会让 σ 失去意义。

## A3 GKHR 算法（论文 Algorithm 1，逐行照抄，共 6 行）
1) μ(x_i) = (1/n) Σ_{j=1..n} k(x_j, x_i)        # 与全池的平均相似度，只算一次
2) β_1 = 1；S_0(x_i) = 0（∀i）；Σ*_1 = ∅
3) for p = 1 … m:
4)     i*_p = argmin_{i ∈ [n] \ Σ*_p} [ S_{p−1}(x_i) − α·μ(x_i) ]
5)     ∀ i ∈ [n]:  S_p(x_i) = (1 − β_p)·S_{p−1}(x_i) + β_p·k(x*_{i_p}, x_i)
6)     Σ*_{p+1} = Σ*_p ∪ {i*_p}；β_{p+1} = 1/(p+1)
    return Σ*_{m+1}
读法（写进代码注释）：S 是"与已选集合的平均相似度"，μ 是"与全池的平均相似度"；min(S − αμ) 即同时压低 S（别与已选重复）和抬高 μ（仍在分布中心）。p=1 时 S_0=0 ⇒ 第一步等价于选 μ 最大者，即全池最"中心"的样本。第 5 行是增量更新，避免每轮重算 Σ_{j∈Σ}k(x*_j, x_i)，这正是 O(mn) 的来源。

## A4 复杂度与实现要点
- 理论 O(m·n) 次核计算。官方 RDSS.py 用 np.delete 逐轮删行 + 逐元素重算，实际另有 O(m·n·d) 拷贝，m=4000 / 大池时会到小时级。
- 参考骨架（与 Algorithm 1 语义等价，复杂度降到 O(mn)；用它替换官方循环，不改算法本身）：

  def gkhr(X, m, alpha, gamma):
      n = X.shape[0]
      mu = np.mean(gaussiankernel(X, X, gamma), axis=1)      # (n,) 即 1/n Σ_j k(x_i,x_j)
      S = np.zeros(n); selected = np.zeros(n, dtype=bool); out = np.empty(m, dtype=np.int64)
      for p in range(1, m + 1):
          cand = np.where(~selected)[0]
          j = cand[np.argmin(S[cand] - alpha * mu[cand])]
          selected[j] = True; out[p - 1] = j
          beta = 1.0 / p
          S[cand] = (1 - beta) * S[cand] + beta * gaussiankernel(X[j:j+1], X[cand], gamma).ravel()
      return out

- 保真要求（写进 tests/）：同特征、同 m、同 α 下，你的实现与官方 RDSS.py 必须输出**完全相同**的索引集合（用 m=250 小规模做一致性测试）；若不等，先查 γ 与 α 取值，再查索引顺序。
- K 过大（n=5e4 时 2.5e9 元素）时按需算行并缓存，或分块 float32；μ 只需一趟。

## A5 下游训练配方（论文 7.1 + 指导书要求）
- 代码库：论文用 USB（Unified Semi-supervised Learning Benchmark）封装 FixMatch/FlexMatch/FreeMatch；课程统一用 FixMatch。
- 优化器 SGD，momentum 0.9，lr 0.03，weight decay 5e-4，cosine 衰减。
- 主干 WRN-28-2（论文对 CIFAR 用的就是它）。
- 论文 5 次独立运行取均值±标准差；课程最低 3 个训练种子。
- FixMatch 损失（指导书原文给出，照此实现）：
    L = L_s + λ_u·L_u
    L_u = E[ 1(max q ≥ τ)·CE( p(y | A(u)), argmax q ) ]
    q = p(y | α_w(u))，α_w 弱增强、A 强增强；τ、λ_u、μ（有/无标签 batch 比）在三种选样方法间必须完全一致。
- 先做 sanity check：只用选后 m 个样本做纯监督训练（对应论文 Table 2 的 SL 视角），确认标签揭示无泄漏、准确率显著高于 10%，再上 FixMatch。

### A5.2 验证集策略（防止数据泄漏）
1. 从 CIFAR-10 的 50000 训练集中划出 5000 张（10%）做验证集，用 **seed=0** 预先生成并固定索引文件（`splits/val_indices_seed0.json`）。
2. 验证集**唯一用途**：在 FixMatch 训练过程中选择最佳 checkpoint（保存验证集 Acc 最高的 epoch）。
3. 验证集**绝对禁止**：调 FixMatch 超参（τ / λ_u / μ / 增强策略）、调选择器参数（γ / α）、报告最终结果。所有超参决策必须在 P0-P1 阶段完成，中途不改。
4. 三种选择器（Random / k-center / RDSS）都在剩余 **45000 张训练池**上选样本，确保公平。

## A7 论文 ↔ 官方代码的已知不一致（逐条记录，不许悄悄改了不说明）
1. 核带宽：论文 σ = 全池距离中位数；RDSS.py 的 gaussiankernel 默认写死 gamma=0.5。→ 主实验按 median 口径，另跑一次 gamma=0.5 复现官方行为，作为"实现差异"写进报告。
2. 特征取法：论文是 final [CLS] token；get_cifar_feature.py 用 model(...).pooler_output（由 [CLS] 经 pooler 派生，近似而非逐位相同）。→ 报告写明实际取法，三方法必须同一种、中途不换。
3. 基线命名：论文对照是 Random / k-Means / Stratified / USL / ActiveFT；课程要求 **k-center（core-set 贪心）**，不是 k-Means。→ 注明"k-center 为课程新增基线，非论文原基线"。
4. 预算与数据：论文 CIFAR-10 m ∈ {40,250,4000}；课程 m ∈ {250,1000}。
5. SVHN 分支：RDSS.py 的 SVHN 误用 cifar100 预算列表（复制粘贴错误，L94 应为 num_samples_svhn），且 np.array(字典) 会退化成 object 数组。→ 课程不跑 SVHN，标注废弃或修复，不要假装可用。
6. **μ 的对角线处理**：论文 Algorithm 1 定义 μ(x_i) = (1/N) Σ_{j=1}^{N} k(x_j, x_i)（包含自身 k(x_i, x_i)=1）；官方 RDSS.py L22 显式去掉对角线：`mu = kernel(data); mu = mu - np.diag(np.diag(mu))`，即 μ(x_i) = (1/N) Σ_{j≠i} k(x_j, x_i)。→ 在 §A4 骨架实现中需决定是否去对角线；**先按论文口径（不去）实现，再跑一致性测试**，若官方输出不同则切换为去对角线版本并记录差异。

## A8 选择质量代理指标（课程侧，公式自定义但必须写清，且只在选完后用标签诊断）
- 类分布熵 H(p_class)，p_class 为所选集在 10 类上的经验分布
- 覆盖率 coverage = |∪_{i∈S} N_10(x_i)| / n（N_10 为特征空间 10 近邻集合）
- 冗余度 mean_{i∈S} NNdist(x_i, S\{x_i})（越小越重复）；另报"最近邻同类比例"
- 伪标签精度：训练后期用模型预测未标注池，事后与真实标签比对，**只作诊断**，标题注明"诊断用，不参与选样"

## B6 合规执行顺序（8 步，顺序不能反）
1. 固定 CIFAR-10 训练池与测试集；每个种子**预先**保存池索引，禁止各方法偷换池

**三种选择器实现要点**：
- **Random**（最易实现，但不可省略）：`np.random.choice(45000, size=m, replace=False)`，用 SELECTION_SEEDS 生成三个版本。
- **k-center / Core-Set 贪心**（课程新增基线）：
  ```python
  def kcenter_greedy(X, m, seed=42):
      # X: (n, d) 特征矩阵；m: 要选的数量
      rng = np.random.RandomState(seed)
      n = X.shape[0]
      selected = [rng.randint(n)]              # 1. 随机初始化第一个中心点
      dists = np.linalg.norm(X - X[selected[0]], axis=1)
      for _ in range(m - 1):
          j = np.argmax(dists)                 # 2. 选离已选集合最远的点
          selected.append(j)
          new_dists = np.linalg.norm(X - X[j], axis=1)
          dists = np.minimum(dists, new_dists) # 3. 更新：到已选集合的最近距离
      return np.array(selected)
  ```
  注意：k-center 的结果依赖初始化种子（SELECTION_SEEDS），因此必须报 3 个种子的均值±标准差；RDSS 完全确定性，不需要种子（但仍用 TRAIN_SEEDS 跑 FixMatch）。
- **RDSS / GKHR**：用 §A4 优化骨架（而非官方 np.delete 版本），先尝试不去对角线的 μ（论文口径），跑一致性测试；若与官方输出不同则切换为去对角线版本（RDSS.py L22）。

通过条件：同预算下三份索引 + 选择耗时表 + 二维 toy 直觉图（用 generate_visualization_data.py 的数据复现 visualization.py 的可视化，验证三种选择器的差异）。

    --labeled-list selections/random_m250_s42.json `
    --val-indices splits/val_indices_seed0.json `
    --test-indices splits/test_indices.json `
    --seed 42 `
    --output-dir results/p3_sanity_random_m250_seed42

# === P4 主实验矩阵（18 次，可手动批量跑）===
# 外层 m，中层选择器，内层种子
foreach ($m in 250,1000) {
    foreach ($method in @("random","kcenter","rdss")) {
        foreach ($seed in 42,1234,12345) {
            python scripts/train_fixmatch.py `
                --config configs/fixmatch.yaml `
                --labeled-list selections/$($method)_m$($m)_s$($seed).json `
                --val-indices splits/val_indices_seed0.json `
                --test-indices splits/test_indices.json `
                --seed $seed `
                --output-dir "results/m$($m)/$($method)/seed$($seed)"
        }
    }
}

# === P5 消融（α 敏感性）===
foreach ($alpha in 0,0.9368,1) {
    python scripts/selection_rdss.py `
        --budget 250 --alpha $alpha `
        --feature-path features/cifar10_trainpool_clip.npy `
        --output selections/rdss_m250_alpha$alpha.json
    foreach ($seed in 42,1234,12345) {
        python scripts/train_fixmatch.py `
            --config configs/fixmatch.yaml `
            --labeled-list selections/rdss_m250_alpha$alpha.json `
            --seed $seed `
            --output-dir "results/ablation_alpha/alpha$alpha/seed$seed"
    }
}

# === P6 汇总（主表 + 图表，由脚本统一生成，禁止手工抄数字）===
python scripts/summarize_main_table.py --results-dir results/ --output results/main_table.csv
python scripts/plot_budget_curve.py    --results-dir results/ --output figures/budget_curve.png
python scripts/plot_alpha_sensitivity.py --results-dir results/ --output figures/alpha_sensitivity.png
python scripts/visualize_tsne.py       --feature-path features/cifar10_trainpool_clip.npy `
    --selections-dir selections/ --output figures/feature_tsne.png

### 命令模板中的路径约定
- 所有数据、特征、索引文件、选择结果都放在 `project/` 子目录下（不是工作区根目录）
- `configs/` 放 `.yaml` 配置；`scripts/` 放可执行脚本；`results/` 按 `m{预算}/{方法}/seed{种子}` 三级组织
- 每个训练结果目录下必须有：`train.log`（完整日志）、`best_model.pth`（最佳 checkpoint）、`metrics.json`（Acc/Macro-F1/时长/显存）、`config.yaml`（本次运行的配置快照）
